# 📚 CSE382 — Introduction to Machine Learning

> Assignments and implementations for the Machine Learning course at the Faculty of Engineering, Ain Shams University.

## 📝 Assignments

### Assignment 01 — Bayes Classifier
Implementing a Bayes optimal classifier for a 3-class problem using multivariate Gaussian distributions.

**What's covered:**
- Likelihood contour plots for each class
- Decision map over a 2D region with decision boundaries
- Effect of changing prior probabilities
- Posterior probability heatmaps
- Bayes error estimation
- Confusion matrix via Monte-Carlo simulation
